# PRD — The Achievers Rebuild (exam, 1-day)

## Goal
Rank #1: student-friendly, fast, interface-focused rebuild of theachievers.com.np. 6 pages minimum.

## Source of truth (originals)
- `The-Achievers-Brochure.pdf`: name, stats (100K+, 30+, 24/7, 95%+), 8 subjects, 11 teachers, 4-step journey, 5 FAQs, contacts (981-0686665, 976-9884993, info.theachiever@gmail.com, Puspalal Chowk Mahendranagar), payments (eSewa/Khalti/Fonepay).
- Live site: courses/teachers/fees — no invented fees; show “contact for current fee” where live.

## Pages (6)
1. index.html — hero, stats, top courses, why/how, teachers preview, testimonials, FAQ, demo CTA
2. courses.html — courses + syllabus combined (#syllabus), filter + search (UI only)
3. teachers.html — 11 original faculty
4. about.html — mission, journey, app
5. contact.html — counselling + contact + map + payments
6. demo.html — demo booking + free mock/counselling

## Student-friendly requirements
- Mobile-first, 44px targets, sticky Call/Demo bar, readable 16px+, AA contrast
- 1 H1/page, semantic sections, alt/aria, keyboard focus, skip link
- Forms validate inline, success message, no backend

## Non-goals
No auth, no real checkout, no backend. Visual only.
